== Code Generation from XSD

cxf-xjc-plugin

* The plugin until version 3.x support generate code with "javax.". PROFILE
* The plugin from version 4.x will generate code with new "jakarta.". DEFAULT MAVEN

.Code generation with xjc maven plugin
----
<plugin>
    <groupId>org.apache.cxf</groupId>
    <artifactId>cxf-xjc-plugin</artifactId>
    <version>${cxf-xjc-plugin.version}</version>
</plugin>
----




=== Javax (JavaEE 8, Jakarta 8)

Require

javax.activation (the JavaBeans Activation Framework or JAF) 
is required by XJC, the JAXB binding compiler. 
Under the hood, XJC relies on classes like javax.activation.DataSource 
and javax.activation.DataHandler to process binary data types 
and MIME attachments when generating Java classes from an XML schema


From Java 9 those package where "removed" from JDK, so is required to be declared in maven
